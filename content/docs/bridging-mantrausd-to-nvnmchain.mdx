<Info>
  **NVNM Chain** is a CCV consumer chain of **MANTRA Chain**. The gas token on NVNM Chain is **wmantraUSD**, bridged from the provider chain via IBC. There is no standalone bridge UI — tokens are obtained by wrapping `mantraUSD` on MANTRA Chain and IBC-transferring the wrapped denom (`wmantraUSD`) to your NVNM Chain address.
</Info>

Tokens are obtained by wrapping `mantraUSD` (`mmUSD → wmmUSD`) on the parent MANTRA Chain (`mantra-dukong-1` for testnet, `mantra-1` for mainnet) and IBC-transferring to your NVNM Chain address (`nvnm-testnet-1` or `nvnm-1`).

## Prerequisites

- `mantrachaind` binary installed
- `nvnmchaind` binary installed
- `cast` ([Foundry](https://book.getfoundry.sh/getting-started/installation)) installed
- A `mantraUSD` balance available on MANTRA Chain
  - If you have USDC/USDT on other chains, the [mantraUSD Express Bridge](https://get.mantrausd.com) is the fastest way to acquire `mantraUSD`
  - See [Acquiring mantraUSD](/resources/acquiring-mantrausd) for all supported paths

### Wallet setup

Import your wallet as an account in Foundry and into the `mantrachaind` and `nvnmchaind` binaries:

```bash
WALLET_ACCOUNT_NAME=<name-of-your-wallet-here>

mantrachaind keys add $WALLET_ACCOUNT_NAME --recover
nvnmchaind keys add $WALLET_ACCOUNT_NAME --recover
cast wallet import $WALLET_ACCOUNT_NAME --interactive --mnemonic

# Ledger is also viable
mantrachaind keys add $WALLET_ACCOUNT_NAME --ledger
nvnmchaind keys add $WALLET_ACCOUNT_NAME --ledger
# For any cast commands below, replace `--account $WALLET_ACCOUNT_NAME`
# with `--ledger` when using a Ledger device.
```

[Keplr](https://github.com/chainapsis/keplr-chain-registry/pull/1461) natively supports both NVNM Chain Cosmos (cointype `118`) and NVNM Chain EVM (cointype `60`, `0x` address).

Choose the tab matching the network you are bridging to. The commands in later steps use these variables and are identical across networks.

      2. [Squid Router](https://app.squidrouter.com/?fromChain=ethereum&toChain=mantra&fromToken=usdt&toToken=mantrausd)
      3. [Lucid](https://app.lucidlabs.fi/bridge) (bridge USDC/USDT to MANTRA Chain) + [QuickSwap](https://dapp.quickswap.exchange/swap?type=v4&from=0x5E76be0F4e09057D75140216F70fd4cE3365bb29&to=0xd2b95283011E47257917770D28Bb3EE44c849f6F) (swap to `mantraUSD`)

## Step 2 — Approve and wrap mantraUSD on MANTRA Chain

<Note>
  This step can also be completed by interacting with the smart contract directly on Blockscout:

  - **Testnet:** [`0x36A28B8C8FFD00bEE440dB8273D57451FBeAf767`](https://explorer.dukong.io/token/0x36A28B8C8FFD00bEE440dB8273D57451FBeAf767?tab=read_write_contract)
  - **Mainnet:** [`0x5EB619e3dcA586c321Bb83282D2916577B5c383d`](https://blockscout.mantrascan.io/token/0x5EB619e3dcA586c321Bb83282D2916577B5c383d?tab=read_write_contract)

  Both `approve` and `depositFor` expect the amount in 6 decimals (the `mantraUSD` precision).
</Note>

<Steps>
  <Step title="Approve the wmantraUSD contract to spend your mantraUSD">
    ```bash
    # AMOUNT_MANTRA_USD uses 6 decimals (mantraUSD on MANTRA Chain)
    cast send $MANTRA_USD_ADDRESS "approve(address,uint256)" \
      $WRAPPED_MANTRA_USD_ADDRESS $AMOUNT_MANTRA_USD \
      --rpc-url $MANTRA_EVM_NODE \
      --account $WALLET_ACCOUNT_NAME --chain $MANTRA_CHAIN_ID_EVM
    ```
  </Step>
  <Step title="Wrap (depositFor) mantraUSD into wmantraUSD">
    `depositFor` requires the destination as a hex (`0x`) address. Convert your `nvnm1...` bech32 address to hex using either binary:

    ```bash
    HEX_ADDRESS=$(nvnmchaind q evm bech32-to-0x $NVNM_ADDRESS)
    # or: HEX_ADDRESS=$(mantrachaind q evm bech32-to-0x <your_mantra_bech32_address>)

    # AMOUNT_MANTRA_USD uses 6 decimals (mantraUSD on MANTRA Chain)
    cast send $WRAPPED_MANTRA_USD_ADDRESS "depositFor(address,uint256)" \
      $HEX_ADDRESS $AMOUNT_MANTRA_USD \
      --rpc-url $MANTRA_EVM_NODE \
      --account $WALLET_ACCOUNT_NAME --chain $MANTRA_CHAIN_ID_EVM
    ```
  </Step>
</Steps>

## Step 3 — Convert ERC20 to IBC denom on MANTRA Chain

Convert the wrapped ERC20 balance into the Cosmos-side IBC denom so it can be transferred over IBC.

```bash
mantrachaind tx erc20 convert-erc20 \
  $WRAPPED_MANTRA_USD_ADDRESS $AMOUNT_WMANTRA_USD \
  --from $WALLET_ACCOUNT_NAME \
  --yes --chain-id $MANTRA_CHAIN_ID \
  --gas auto --gas-adjustment 2 \
  --gas-prices 40000000000amantra \
  --node $MANTRA_RPC_NODE
```

## Step 4 — IBC transfer to NVNM Chain

Send the wrapped denom from MANTRA Chain to your NVNM Chain address over the IBC transfer channel.

```bash
mantrachaind tx ibc-transfer transfer transfer $MANTRA_NVNM_IBC_CHANNEL \
  $NVNM_ADDRESS \
  ${AMOUNT_WMANTRA_USD}${WRAPPED_MANTRA_USD_DENOM} \
  --from $WALLET_ACCOUNT_NAME \
  --yes --chain-id $MANTRA_CHAIN_ID \
  --gas auto --gas-adjustment 2 \
  --gas-prices 40000000000amantra \
  --node $MANTRA_RPC_NODE
```

<Note>
  The MANTRA-side transfer channel is `channel-13` on `mantra-dukong-1` (testnet) and `channel-9` on `mantra-1` (mainnet). On NVNM Chain, the corresponding channel is `channel-1`.
</Note>

## Verify your balance

Query your NVNM Chain bank balance for the IBC denom:

```bash
nvnmchaind query bank balance \
  $NVNM_ADDRESS \
  $CONSUMER_DENOM \
  --node $NVNM_RPC_NODE
```

Expected output:

```yaml
balance:
  amount: "<value of AMOUNT_WMANTRA_USD>"
  denom: ibc/00E24F149F01782E2C423BDB114C98D6C657DFC583124389192187BF8DC3A1AD
```
