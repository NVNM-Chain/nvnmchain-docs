---
title: "How to Connect Wallets to Devnet"
icon: "hammer"
---

This guide walks you through connecting MetaMask, Rabby, and Keplr to the NVNM Chain DevNet powered by TEMPO EVM.

<Note>
  If you haven't installed your wallet yet, follow the [MetaMask](/getting-started/how-to-setup-your-metamask-wallet), [Rabby](/getting-started/how-to-setup-your-rabby-wallet), or [Keplr](/getting-started/how-to-setup-your-keplr-wallet) setup guide first.
</Note>

---

<Steps>
  <Step title="Open network settings">
    Within the EVM Wallet Extension of your choice, you should navigate to **Settings** > **Network Settings**, then find the configuration for **Add a custom network**.
  </Step>

  <Step title="Enter NVNM Tempo DevNet network details">
    Fill in the following details:

    | Parameter | Value |
    | --- | --- |
    | Network Name | `NVNM Tempo Devnet 1` |
    | RPC URL | `https://rpc.nvnm.canary.mantrachain.dev` |
    | Chain ID | `787222` |
    | Currency Symbol | `pathUSD` |
    | Block Explorer URL | `https://scan.nvnm.canary.mantrachain.dev` |

    Click **Save** to add the network.
  </Step>

  <Step title="Switch to NVNM Tempo Devnet 1">
    Select **NVNM Tempo Devnet 1** from the network dropdown. Your wallet is now connected to the NVNM Chain Devnet, with the native gas token shown as pathUSD.
  </Step>
</Steps>
