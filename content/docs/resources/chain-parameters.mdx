## Token Denominations

<Info>
  **Understanding Denoms:**

  As of the moment, NVNM Chain has **NOT** launched with a native token. The chain operates using a wrapped mantraUSD token, which is used for transaction fees and other on-chain activities. The wrapped mantraUSD token is represented by the `wmantraUSD` denomination.
</Info>

## System Requirements

### Minimum Requirements

| Component | Specification |
| --- | --- |
| CPU | 4\+ cores |
| RAM | 16 GB |
| Storage | 500GB\+ SSD, 5000\+ IOPS |
| Network | 25\+ Mbps |
| OS | Ubuntu 20.04\+ or macOS |

<Note>
  Bare metal servers are recommended over cloud VMs for optimal validator performance.
</Note>

### Building from Source

- Go 1.23.x required for building from source
