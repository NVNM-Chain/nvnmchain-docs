# Mainnet

<Tabs>
  <Tab title="NVNM Chain L2: Mainnet">
    **Seed Nodes**

    ```
    5a95d8c5f453421ab272ef1178e3cb4c1f09930c@seed0.mainnet.nvnmchain.io:26656
    1a630e445f2a032aa15f00be4e14ae5f9e87d470@seed1.mainnet.nvnmchain.io:26656
    e2fe167d03e79fa98db2bd36247ba367c7bcdbb7@seed2.mainnet.nvnmchain.io:26656
    ```

    **Additional P2P Peers**

    To add these peers to your node configuration:

    1. Edit your `config.toml` file:

    ```bash
    nano ~/.nvnmchain/config/config.toml
    ```

    2. Add the seed nodes:

    ```toml
    # Comma separated list of seed nodes to connect to
    seeds = ""
    ```

    3. Optionally, add some persistent peers:

    ```toml
    # Comma separated list of nodes to keep persistent connections to
    persistent_peers = ""
    ```

    **Addrbook**

    You can also bootstrap your node with a pre-existing addrbook:

    ```bash
    wget -O ~/.nvnmchain/config/addrbook.json https://raw.githubusercontent.com/NVNM-Chain/net-nvnmchain/main/nvnm-1/addrbook.json
    ```
  </Tab>
