This page lists peer information for connecting to NVNM Chain NEXT (L1) networks.

# DevNet

`nvnm-tempo-devnet-1` (EVM Chain ID `787222`) is a fork of [Tempo](https://github.com/tempoxyz/tempo) — `reth` execution + Commonware Simplex BFT consensus. Peering is configured via `reth`'s `--trusted-peers` flag with `enode://` URLs. See [Network Details](/resources/network-details) for RPC/explorer endpoints.

<Note title="Closed sandbox devnet — not externally reachable">
  This devnet's P2P port is **not** exposed outside — there is no public load balancer for it. The peers below only work for nodes running inside that cluster network.
</Note>
