# Testnet

`nvnm-next-testnet-1` (EVM Chain ID `787223`) runs `reth` execution + Commonware Simplex BFT consensus. Peering is configured via `reth`'s `--trusted-peers` flag with `enode://` URLs. See [Network Details](/resources/network-details) for RPC/explorer endpoints.

<Note title="Private peers — public peer coming soon">
  These are currently private peers reachable only from within the cluster. Public peer endpoints for external connections will be published soon.
</Note>
