---
title: "How to Connect Wallets to Testnet"
icon: "hammer"
---

This guide walks you through connecting MetaMask, Rabby, and Keplr to the NVNM Chain Testnet powered by TEMPO EVM.

<Note>
  If you haven't installed your wallet yet, follow the [MetaMask](/getting-started/how-to-setup-your-metamask-wallet), [Rabby](/getting-started/how-to-setup-your-rabby-wallet), or [Keplr](/getting-started/how-to-setup-your-keplr-wallet) setup guide first.
</Note>

---

<Steps>
  <Step title="Open network settings">
    Within the EVM Wallet Extension of your choice, you should navigate to **Settings** > **Network Settings**, then find the configuration for **Add a custom network**.
  </Step>

  <Step title="Enter NVNM Tempo Testnet network details">
    Fill in the following details:

    | Parameter | Value |
    | --- | --- |
    | Network Name | `NVNM Tempo Testnet 1` |
    | RPC URL | `https://rpc.nvnm.testnet.nvnmchain.io` |
    | Chain ID | `787223` |
    | Currency Symbol | `nUSD` |
    | Block Explorer URL | `https://explorer.nvnm.testnet.nvnmchain.io` |

    Click **Save** to add the network.
  </Step>

  <Step title="Switch to NVNM Tempo Testnet 1">
    Select **NVNM Tempo Testnet 1** from the network dropdown. Your wallet is now connected to the NVNM Chain Testnet, with the native gas token shown as nUSD.
  </Step>
</Steps>
