This guide walks you through connecting MetaMask, Rabby, and Keplr to the NVNM Chain testnet, _(powered by the L1 MANTRA Dukong Testnet)_.

<Note>
  If you haven't installed your wallet yet, follow the [MetaMask](/getting-started/how-to-setup-your-metamask-wallet), [Rabby](/getting-started/how-to-setup-your-rabby-wallet), or [Keplr](/getting-started/how-to-setup-your-keplr-wallet) setup guide first.
</Note>

---

## MetaMask

<Steps>
  <Step title="Open network settings">
    Click the network dropdown at the top of the MetaMask extension, then select **Add a custom network**.
  </Step>

  <Step title="Enter testnet network details">
    Fill in the following details:

    | Parameter | Value |
    | --- | --- |
    | Network Name | `NVNM Testnet` |
    | RPC URL | `https://evm.testnet.nvnmchain.io` |
    | Chain ID | `787111` |
    | Currency Symbol | `NVNM` |
    | Block Explorer URL | `https://explorer.evm.testnet.nvnmchain.io` |

    Click **Save** to add the network.

    <Frame>
      <img src="/images/connect-testnet/metamask-network-settings.png" alt="MetaMask Network Settings" />
    </Frame>
    <Frame>
      <img src="/images/connect-testnet/metamask-add-network.png" alt="MetaMask Add Network" />
    </Frame>
  </Step>

  <Step title="Switch to NVNM Testnet">
    Select **NVNM Testnet** from the network dropdown. Your wallet is now connected to the NVNM Chain testnet, with the native gas token shown as MANTRA USD.
  </Step>
</Steps>

---

## Rabby

<Steps>
  <Step title="Open More Chains">
    In the Rabby extension, click the chain selector (top-left) and select **More chains** to open the chain browser.
  </Step>

  <Step title="Search for NVNM Testnet">
    Use the search bar to look for `NVNM`. If it appears, click **Add** to enable it.

    If it does not appear, add it manually using **Settings → Custom RPC** with the network details above.
  </Step>

  <Step title="Switch to NVNM Testnet">
    Select **NVNM Testnet** from the chain selector to connect.
  </Step>
</Steps>

---

## Keplr

<Steps>
  <Step title="Open Manage Chain Visibility">
    Open the Keplr extension, go to **Settings**, and select **Manage Chain Visibility**.
  </Step>

  <Step title="Search for NVNM Testnet">
    Search for `nvnm testnet` and enable **NVNM Testnet** from the list.

    <Frame>
      <img src="/images/connect-testnet/keplr-add-nvnm-testnet.png" alt="Keplr Add NVNM Testnet" />
    </Frame>
  </Step>

  <Step title="Confirm and save">
    Click **Save** to add NVNM Testnet to your Keplr wallet.
  </Step>
</Steps>

<Tip>
  Check the [Network Details](/docs/resources/network-details) page for the latest testnet endpoints and chain parameters.
</Tip>
