This guide walks you through connecting MetaMask, Rabby, and Keplr to the NVNM Chain testnet, _(powered by the L1 MANTRA Dukong Testnet)_.

<Note>
  If you haven't installed your wallet yet, follow the [MetaMask](/getting-started/how-to-setup-your-metamask-wallet), [Rabby](/getting-started/how-to-setup-your-rabby-wallet), or [Keplr](/getting-started/how-to-setup-your-keplr-wallet) setup guide first.
</Note>

---

## MetaMask

<Steps>
  <Step title="Open network settings">
    Click the network dropdown at the top of the MetaMask extension, then select **Add a custom network**.
  </Step>

  <Step title="Enter testnet network details">
    Fill in the following details:

    | Parameter | Value |
    | --- | --- |
    | Network Name | `NVNM Testnet` |
    | RPC URL | `https://evm.testnet.nvnmchain.io` |
    | Chain ID | `787111` |
    | Currency Symbol | `mantraUSD` |
    | Block Explorer URL | `https://explorer.evm.testnet.nvnmchain.io` |

    Click **Save** to add the network.
  </Step>

  <Step title="Switch to NVNM Testnet">
    Select **NVNM Testnet** from the network dropdown. Your wallet is now connected to the NVNM Chain testnet, with the native gas token shown as mantraUSD.
  </Step>
</Steps>

<Tip>
  For a more detailed walkthrough with screenshots, see [Add NVNM Testnet to MetaMask](/getting-started/how-to-setup-your-metamask-wallet#add-nvnm-testnet-to-metamask).
</Tip>

## Rabby

<Steps>
  <Step title="Open Settings">
    Click the **settings gear** icon in the top-right of the Rabby extension.
  </Step>

  <Step title="Add Custom Network">
    In Settings, click **Add Custom Network**, then click **Add Custom Network** again on the next screen.
  </Step>

  <Step title="Enter network details and confirm">
    Fill in the following details, then click **Confirm**.

    | Parameter | Value |
    | --- | --- |
    | Chain ID | `787111` |
    | Network Name | `NVNM Testnet` |
    | RPC URL | `https://evm.testnet.nvnmchain.io` |
    | Currency Symbol | `mantraUSD` |
    | Block Explorer URL | `https://explorer.evm.testnet.nvnmchain.io` |
  </Step>
</Steps>

<Tip>
  For a more detailed walkthrough with screenshots, see [Add NVNM Testnet to Rabby](/getting-started/how-to-setup-your-rabby-wallet#add-nvnm-testnet-to-rabby).
</Tip>

---

## Keplr

<Steps>
  <Step title="Open Manage Chain Visibility">
    Open the Keplr extension, go to **Settings**, and select **Manage Chain Visibility**.
  </Step>

  <Step title="Search for NVNM Testnet">
    Search for `nvnm testnet` and enable **NVNM Testnet** from the list.
  </Step>

  <Step title="Confirm and save">
    Click **Save** to add NVNM Testnet to your Keplr wallet.
  </Step>
</Steps>

<Tip>
  For a more detailed walkthrough with screenshots, see [Add NVNM Testnet to Keplr](/getting-started/how-to-setup-your-keplr-wallet#add-nvnm-testnet-to-keplr).
</Tip>
