This guide walks you through installing Rabby Wallet and adding the NVNM Chain network.

<Note>
  Rabby is an open-source EVM wallet built for DeFi users. It includes built-in transaction simulation and security checks, making it a strong alternative to MetaMask for EVM chains.
</Note>

## Installation

<Steps>
  <Step title="Install Rabby">
    1. Visit [https://rabby.io](https://rabby.io).
    2. Hit the download button for **Chrome**. You will be directed to the Chrome Web Store.

        <Frame>
          ![Rabby website download for Chrome button](/images/rabbysetup/hitdownlioadforchrome.png)
        </Frame>

    3. Click **Add to Chrome**.

        <Frame>
          ![Google Chrome add Rabby extension](/images/rabbysetup/addchrome.png)
        </Frame>

    4. On the pop up, click **Add extension**.

        <Frame>
          ![Google Chrome add Rabby extension confirm](/images/rabbysetup/addext.png)
        </Frame>

    5. After adding the Rabby extension, Rabby will automatically open. You can also make sure it's easily accessible in your toolbar by clicking the jigsaw icon in the top-right of the screen, and hitting the pin icon.

        <Frame>
          ![Google Chrome pin Rabby extension](/images/rabbysetup/pinit.png)
        </Frame>

    <Warning>
      Only install Rabby from the official site at [rabby.io](https://rabby.io) or directly from the Chrome Web Store. Avoid third-party download links.
    </Warning>
  </Step>

  <Step title="Create or import a wallet">
    Open the Rabby extension and choose one of the following:

    - **Create a new address** — Follow the prompts to generate a new wallet and back up your seed phrase.
    - **Import an existing wallet** — Enter your 12- or 24-word seed phrase, or import via private key or hardware wallet.

    <Warning>
      **Never** share your seed phrase or private key with anyone.
    </Warning>
  </Step>
</Steps>

## Add NVNM Testnet to Rabby

<Steps>
  <Step title="Open Settings">
    Click the **settings gear** icon in the top-right of the Rabby extension.

    <Frame>
      ![Rabby extension home screen](/images/rabbysetup/settings.png)
    </Frame>
  </Step>

  <Step title="Add Custom Network">
    In Settings, click **Add Custom Network**.

    <Frame>
      ![Rabby settings Add Custom Network option](/images/rabbysetup/addcustomnetwork.png)
    </Frame>

    On the next screen, click **Add Custom Network** again.

    <Frame>
      ![Rabby Add Custom Network screen](/images/rabbysetup/addcustomnetwork2.png)
    </Frame>
  </Step>

  <Step title="Enter network details and confirm">
    Fill in the following details, then click **Confirm**.

    | Parameter | Value |
    | --- | --- |
    | Chain ID | `787111` |
    | Network Name | `NVNM Testnet` |
    | RPC URL | `https://evm.testnet.nvnmchain.io` |
    | Currency Symbol | `mantraUSD` |
    | Block Explorer URL | `https://explorer.evm.testnet.nvnmchain.io` |

    <Frame>
      ![Rabby Add Custom Network form filled with NVNM Testnet details](/images/rabbysetup/adddataandconfirm.png)
    </Frame>
  </Step>
</Steps>
