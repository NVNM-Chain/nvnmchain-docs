This guide walks you through connecting MetaMask, Rabby, and Keplr to NVNM Chain Mainnet.

<Warning title="Mainnet details pending">
  NVNM Chain L1 Mainnet has not launched yet. Every value marked `TBD` below is a placeholder. The final values are published on [Network Details](/resources/network-details) first. Do not add this network to your wallet until they are available.
</Warning>

<Note>
  If you haven't installed your wallet yet, follow the [MetaMask](/getting-started/how-to-setup-your-metamask-wallet), [Rabby](/getting-started/how-to-setup-your-rabby-wallet), or [Keplr](/getting-started/how-to-setup-your-keplr-wallet) setup guide first.
</Note>

---

<Steps>
  <Step title="Open network settings">
    In your EVM wallet extension, go to **Settings** > **Network Settings** and open **Add a custom network**.
  </Step>

  <Step title="Enter NVNM Mainnet network details">
    Fill in the following details:

    | Parameter | Value |
    | --- | --- |
    | Network Name | `NVNM Mainnet` |
    | RPC URL | `TBD` |
    | Chain ID | `TBD` |
    | Currency Symbol | `nUSD` |
    | Block Explorer URL | `TBD` |

    Click **Save** to add the network.
  </Step>

  <Step title="Switch to NVNM Mainnet">
    Select **NVNM Mainnet** from the network dropdown. Your wallet is now connected to NVNM Chain Mainnet. NVNM Chain has no native token, so the balance your wallet labels nUSD is a placeholder. To see your real nUSD balance, see [Token balances and fees](/developer-guides/token-balances-and-fees).
  </Step>
</Steps>

<Warning>
  Mainnet transactions are irreversible and nUSD on Mainnet carries real value. Double-check the chain ID and RPC URL against [Network Details](/resources/network-details) before you send funds.
</Warning>
