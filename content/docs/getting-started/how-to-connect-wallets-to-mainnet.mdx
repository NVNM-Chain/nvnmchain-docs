This guide walks you through connecting MetaMask, Rabby, and Keplr to the NVNM Chain mainnet.

---

## MetaMask

<Steps>
  <Step title="Open network settings">
    Click the network dropdown at the top of the MetaMask extension, then select **Add a custom network**.
  </Step>

  <Step title="Enter mainnet network details">
    Fill in the following details:

    | Parameter | Value |
    | --- | --- |
    | Network Name | `NVNM Mainnet` |
    | RPC URL | `https://evm.nvnmchain.io` |
    | Chain ID | `1611` |
    | Currency Symbol | `NVNM` |
    | Block Explorer URL | `https://evm.explorer.nvnmchain.io` |

    Click **Save** to add the network.
  </Step>

  <Step title="Switch to NVNM Mainnet">
    Select **NVNM Mainnet** from the network dropdown. Your wallet is now connected to NVNM Chain mainnet.
  </Step>
</Steps>

<Tip>
  For a more detailed walkthrough with screenshots, see [Add NVNM Mainnet to MetaMask](/getting-started/how-to-setup-your-metamask-wallet#add-nvnm-mainnet-to-metamask).
</Tip>

---

## Rabby

<Steps>
  <Step title="Open More Chains">
    In the Rabby extension, click the chain selector (top-left) and select **More chains** to open the chain browser.
  </Step>

  <Step title="Add the network manually">
    NVNM Mainnet is not yet listed in Rabby's chain registry, so you need to add it manually. Open **Settings → Custom RPC** and add the network with these details:

    | Parameter | Value |
    | --- | --- |
    | Network Name | `NVNM Mainnet` |
    | RPC URL | `https://evm.nvnmchain.io` |
    | Chain ID | `1611` |
    | Currency Symbol | `NVNM` |
    | Block Explorer URL | `https://evm.explorer.nvnmchain.io` |

    Click **Confirm** to save the network.
  </Step>

  <Step title="Switch to NVNM Mainnet">
    Select **NVNM Mainnet** from the chain selector to connect.
  </Step>
</Steps>

<Tip>
  For a more detailed walkthrough with screenshots, see [Add NVNM Mainnet to Rabby](/getting-started/how-to-setup-your-rabby-wallet#add-nvnm-mainnet-to-rabby).
</Tip>

---

## Keplr

<Steps>
  <Step title="Open Manage Chain Visibility">
    Open the Keplr extension, go to **Settings**, and select **Manage Chain Visibility**.
  </Step>

  <Step title="Search for NVNM Mainnet">
    Search for `NVNM` and enable **NVNM Mainnet** from the list.
  </Step>

  <Step title="Confirm and save">
    Click **Save** to add NVNM Mainnet to your Keplr wallet.
  </Step>
</Steps>

<Tip>
  For a more detailed walkthrough with screenshots, see [Add NVNM Mainnet to Keplr](/getting-started/how-to-setup-your-keplr-wallet#add-nvnm-mainnet-to-keplr).
</Tip>
