This guide walks you through installing MetaMask and adding the NVNM Chain network.

<Note>
  MetaMask is the recommended EVM wallet for NVNM Chain as it correctly renders balances for both the NVNM L2 and MANTRA Chain L1.
</Note>

## Installation

<Steps>
  <Step title="Install MetaMask">
    1. Visit [https://metamask.io/](https://metamask.io/).
    2. Hit **Get MetaMask** in the menu bar.

        <Frame>
          ![MetaMask website Get MetaMask button](/images/metamasksetup/hit_GetMetaMask.png)
        </Frame>

    3. Click **Chrome**. You will be directed to the Chrome Web Store.
    4. Click **Add to Chrome**.

        <Frame>
          ![Google Chrome add MetaMask extension](/images/metamasksetup/addtochrome.png)
        </Frame>

    5. On the pop up, click **Add extension**.

        <Frame>
          ![Google Chrome add MetaMask extension confirm](/images/metamasksetup/addextension.png)
        </Frame>

    6. After adding the MetaMask extension, MetaMask will automatically open. You can also make sure it's easily accessible in your toolbar by clicking the jigsaw icon in the top-right of the screen, and hitting the pin icon.

        <Frame>
          ![Google Chrome pin MetaMask extension](/images/metamasksetup/pinextension.png)
        </Frame>

    <Warning>
      Only install MetaMask from the official site or your browser's extension store. Avoid third-party download links.
    </Warning>
  </Step>

  <Step title="Create or import a wallet">
    Open the MetaMask extension and choose one of the following:

    - **Create a new wallet** — Follow the prompts to set a password and save your Secret Recovery Phrase.
    - **Import an existing wallet** — Enter your 12- or 24-word Secret Recovery Phrase.

    <Warning>
      **Never** share your Secret Recovery Phrase with anyone. MetaMask support will never ask for it.
    </Warning>
  </Step>
</Steps>

## Add NVNM Testnet to MetaMask

<Steps>
  <Step title="Open the menu">
    Click the **hamburger menu** (three lines) in the top-right of the MetaMask extension.

    <Frame>
      ![MetaMask extension home screen](/images/metamasksetup/settings.png)
    </Frame>
  </Step>

  <Step title="Go to Networks">
    Select **Networks** from the menu.

    <Frame>
      ![MetaMask menu with Networks option](/images/metamasksetup/networks.png)
    </Frame>

    Then click **+ Add a custom network**.

    <Frame>
      ![MetaMask Manage networks screen](/images/metamasksetup/addcustomnetwork.png)
    </Frame>
  </Step>

  <Step title="Enter network details and save">
    Fill in the following details, then click **Save**.

    | Parameter | Value |
    | --- | --- |
    | Network Name | `NVNM Testnet` |
    | Default RPC URL | `https://evm.testnet.nvnmchain.io` |
    | Chain ID | `787111` |
    | Currency Symbol | `mantraUSD` |
    | Block Explorer URL | `https://explorer.evm.testnet.nvnmchain.io` |

    <Frame>
      ![MetaMask Add network form filled with NVNM Testnet details](/images/metamasksetup/testnetdataandsave.png)
    </Frame>
  </Step>
</Steps>
